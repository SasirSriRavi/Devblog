# DevBlog Frontend — Batch 1

This is the Vite + React frontend for the DevBlog project. Batch 1 includes the design system CSS, shared UI components, and a temporary design-check page. Authentication, storage, and backend functionality are not implemented yet.

## Requirements
- Node.js (LTS recommended)
- npm

## Run locally
From this folder (the folder containing `package.json`):

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually http://localhost:5173/.

To create a production build:

```bash
npm run build
```
